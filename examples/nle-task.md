# NetHack / NLE 手动任务说明

将下面整段作为首次用户消息发给 Agent。它说明任务与实际接口，不依赖模型猜测动作编号。完整游戏规则来自官方 NetHack 3.6 Guidebook，通过 `nethack_guide` 工具按需读取；本文不代替 Guidebook。

```text
你正在通过 NLE 玩 NetHack 3.6.6。目标是存活、探索地下城并找到下行楼梯。你可以通过调用 nethack_guide 来读取官方的 Guidebook 来获取游戏规则、地图符号、怪物、物品、战斗或命令说明。每步动作都要有简短的说明，说明你为什么选择这个动作，不要只调用工具。不要使用 shell、文件读取或其他工具查找隐藏游戏状态。

不要凭记忆猜测，也不要用其他文件或网络工具。nethack_guide 不带 section 时返回目录

工具参数 action 是当前 NetHackScore-v0 动作表的索引，不是键盘字符的编码：
0=确认/更多消息；1=北；2=东；3=南；4=西；5=东北；6=东南；7=西南；8=西北；
9–16=相应八方向的连续移动（本次优先用单步移动）；17=上楼；18=下楼；19=等待；20=踢；21=吃；22=搜索。
这份环境只提供以上 23 个动作，不要使用其他 NetHack 命令的编号。菜单或方向提示需要根据真实返回处理，不能假设工具支持任意键盘输入。

工具返回一段公开信息摘要：
第一行的 position=(x,y) 是位置，x 向右、y 向下，均从 0 开始；hp 是当前/最大生命；depth 是地牢深度；turn 是游戏回合；hunger 是饥饿状态。
message 是游戏消息，优先根据它和地图解释真实结果，不要只凭坐标判断是否发生战斗或其他事件。
map 之后是已显示的字符地图。符号含义以 nethack_guide 为准。

NetHack 是回合制游戏。普通移动到怪物所在格可能攻击；宠物可能阻挡或换位；墙会挡路；搜索可发现隐藏门或陷阱；生命与饥饿会影响生存。移动还可能触发拾取、陷阱或战斗，不能把“退回原格”当作撤销。
首次行动前尚无地图并不会阻止行动；直接从 1–22 中选择一个合理动作，或按 message 的提示操作。不要为了刷新观察反复发送 action=0。只根据实际返回的信息判断位置、危险和目标。
```

# 根部连接状态（2026-11-13）

本文描述当前源码与验证缺口，不构成全部验收通过的声明。React Flow + SVG 承载绘制；`webui/src/tree/geometry.ts` 负责场景几何，`webui/src/geometry/curves.ts` 提供通用曲线运算，`webui/src/geometry/smoothConnection.ts` 输出闭合路径与连接元数据，不依赖 UI、BranchState 或参数 store。

## 起点、方向与父轮廓

子枝的世界起点位于分叉时刻对应的父枝中心线。子枝局部路径先按时间与方向公式生成；实际首个非零段的方向在父枝局部法线上的投影决定 Chance 所在侧，没有非零段时使用初始方向，投影为零保留已选侧。父枝 `forkPoints` 与 Chance 圆心位于该侧父枝外沿，不等同子枝中心线起点。

父枝实际可见闭合轮廓优先取其连接路径；无连接时取普通枝干轮廓、单位置截面或空芽椭圆。普通枝干两端直线封口也属于闭合轮廓。父轮廓平移至子枝局部坐标后参与交点计算。连接不改变生长中心线、调用时间、宽度映射或叶茎／叶片规则。

## 首交点与单侧距离

子枝两侧外沿分别从根向末端寻找与父闭合轮廓的首交点 P。两侧都必须存在交点；“首交点”是沿子侧弧长最早的交点，不额外承诺它是某次离开填充的事件。

令父闭合轮廓周长为 L，交点在父轮廓上的弧长为 p0、p1，`mod` 返回非负余数：

`delta = mod(p1 - p0 + L/2, L) - L/2`。

`delta > 0` 时两侧父方向符号为 `[-1,+1]`，否则为 `[+1,-1]`，用于沿父轮廓远离另一侧交点取点。W 为子枝原始 `trunkWidths[0]`：

- 父侧有效单侧距离 `dP = min(connectionParentRatio × W, L/4)`。
- 子侧有效单侧距离 `dC = min(connectionRootRatio × W, 该侧从 P 到末端的剩余弧长)`。
- 两个比例各默认 0.15、范围 0–2、步长 0.01；它们相互独立，不制造额外枝段。

设该侧方向符号为 s，Q 位于父轮廓弧长 `mod(p + s × dP, L)`，C 位于子外沿弧长 `exitArc + dC`。`Join.exit` 为 P，`exitArc` 为 P 的子侧弧长，**`Join.parentArc` 是 P 的父侧弧长 p，不是 Q 的弧长**；`parentPoint` 为 Q，`childPoint` 为 C，两个 distance 保存有效距离。

## 三次相切与闭合轮廓

令 T 为父轮廓在 Q 的单位切向，v 为子外沿在 C 向末端的单位切向，`u = -s × T`。从 Q 到 C 的三次 Bezier 曲线控制点为：

`B0=Q`，`B1=Q+(2/3)dP u`，`B2=C-(2/3)dC v`，`B3=C`。

两端切向分别沿 u 和 v。闭合序列依次为第一侧相切曲线、该侧 C 之后的外沿、末端直线封口、反向第二侧剩余外沿、反向第二侧相切曲线，再以两条直线经过两侧根起点的中点 root 回到起点。该序列用于可见路径与 bounds；相切公式本身不证明填充覆盖、自交或额外材料符合验收要求。

## 单位置父枝、空枝与 null

- 父枝只有一个路径位置时，非空子枝使用 `roundedBase`：保留两侧外沿与末端封口，以两段三次曲线组成向根后方的半圆近似。半径为子枝两侧根起点距离的一半，控制系数为 0.5522847498。此分支不使用两个连接距离，不输出 `joins`。
- 空枝只画普通芽，不生成连接；其起点同样位于父中心线。
- 任一侧缺交点、两交点父侧弧长差绝对值小于 1e-9，或任一有效距离小于 1e-9 时，`smoothConnection` 返回 null；场景显示普通枝干轮廓，不虚构成功连接。

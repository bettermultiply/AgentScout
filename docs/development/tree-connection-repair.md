## 直接构造

普通外沿生成时保存对应中心线累计位置。根枝提前量映射为负位置；单位置截面使用按弦长累计并居中的位置。以锚点位置二分定位两侧边界，按子侧前进方向选择朝向它的一侧。

设 W 为子侧根宽，a 为所选边界到锚点方向与子侧方向投影绝对值，下限 0.25。父侧两端位置展开量为 `min(2W, W/(2a)+connectionParentRatio×W)`，端点限制在父侧已有范围内。两侧的先后顺序由子侧根横向与父侧切线投影确定。

子侧过渡终点位置为 `min(边界到锚点距离/a+connectionRootRatio×W, 子侧位置总长/2)`。枝侧位置沿用中心线距离；叶茎使用 17 个既有外沿点的弦长累计，不进行弧长积分。取实际 cubic 上的点和切向，de Casteljau 分割保留其后原外沿。

父控制柄长度为 `min(QC弦长/3, max(W/6, 2×父侧参数距离/3))`；子控制柄再限制在根到 C 距离的一半内。两端分别沿朝向连接的父切线与前进子切线。闭合序列为第一侧连接及剩余外沿、末端封口、反向第二侧、经根中点返回起点。

生成的两侧曲线和对应位置一并留存；被连接替换的根部区间映射到新 cubic，后续叶茎与子枝直接消费它，不能读回隐藏普通根部。数据仅在本次 layout 内存活，不增加跨任务缓存。

## 退化与限制

- 零宽、零长度或缺少侧曲线时使用普通轮廓；不返回空轮廓。空枝保持普通芽。单位置非空枝使用其真实截面侧边参与同一构造。
- 短枝至少保留后半位置范围；近切向展开有上述有限限制。父端附近端点会夹到边界端点，不延长父枝。
- 映射不是边界精确弧长；根部连接区域的线性参数映射只是确定性的局部选择。闭合用的根中点直线和枝端封口不参与侧边选择。
- 用户对当前画面的接受不代表穷举极端参数，也不构成没有自交、覆盖缺口或收腰的解析证明。
- 布局结果的连接绘制数据为 `d`、`points`、`stroke`，子枝另保留供界面读取的 `rootWidth`；侧边曲线及位置只在本次布局中供后续连接使用。

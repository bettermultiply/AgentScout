# 投机树绘制参数

参数、默认值、范围和面板标签集中在 `webui/src/tree/tuning.ts`；归一化范围从同一份面板字段定义派生，不另维护。长度为树坐标单位，缩放 z 时一个单位对应 z 个 CSS 像素。面板按树枝、叶茎、叶片、整体分类；树枝组包含段长、方向、粗细、采样、子枝初角、空芽与 Chance 标记。整体组只放共同坐标参考，当前为节点局部原点，不是形态或整体缩放控制。数值输入与滑杆并列，数值输入按 Enter 或离开输入框生效；面板右侧拖柄或左右方向键调整宽度。打开时通过面板 header 的“收起”按钮关闭，关闭后保留“调参”入口；两者不同时显示，避免窄树窗中互相遮挡。header 随面板滚动保持可见。

## 公式

下面 d 是相邻调用开始时间差，t 是调用耗时，clamp 表示限制在给定范围。

| 参数 | 公式与含义 |
| --- | --- |
| 段长系数 K、时间尺度 τ | L=K ln(1+d/τ)，默认 K=60、τ=10000ms。K 线性缩放枝段长度，τ 改变时间映射的弯曲程度。内部和本地存储使用毫秒；面板以秒显示，`scale=1000` 只用于面板输入／显示及派生范围，面板范围 0.5–600 秒对应内部 500–600000 毫秒。 |
| 每截转角 δ、回中范围 R、最大倾角 A | p右=clamp(0.5−[(x−原点)+R sin θ]/(2R),0,1)；θ下一截=clamp(θ±δ,−A,A)。方向按 p右 抽取；默认 δ=18°、R=60、A=72°。 |
| 采样步长 g | 每截分成 max(1,ceil(L/g)) 小步，方向按 3u²−2u³ 插值，位置累加 (sin θ,cos θ)L/步数。 |
| 根宽 W、宽度指数 e、最小枝宽 m | w=max(m,W(剩余调用数/总调用数)^e)，默认根宽 9、e=0.1、m=1.2。当前位置的调用已从剩余数中扣除，因此实际根部可能略小于 W。 |
| 子枝夹角范围 | `childAngleMin=30`、`childAngleMax=90`，字段范围为 5–90°。按父枝上的落点距离从小到大分配，同点沿用观察顺序。优先选上一次分叉距离更远的一侧，距离相同时优先选允许相对夹角更大的一侧，竖直时先向右。某侧无法同时满足最小相对夹角和初始朝下（含水平）时用另一侧。同点同侧的子枝等分该侧可用角度范围，各取等分区间的中点。交换上下限等效，等值保持固定夹角。实际首段仍按逐截方向插值。 |
| 父枝宽度过渡 | 条目位置的宽度取该位置及之前条目扣除后的剩余工作量对应值；条目之间用 smoothstep 平滑过渡，条目位置的数值保持不变。 |
| 起点提前量 / 本枝根宽 | `startLeadRatio=0.5`，范围 0–3、步长 0.05。仅无父连接的多点根枝可见轮廓补入 P0′=P0−unit(P1−P0)×startLeadRatio×trunkWidths[0]；零首段方向回退为 `(sin(initialAngle), cos(initialAngle))`，不抛异常。补点宽度等于首宽。普通根枝轮廓及供子枝连接使用的父闭合轮廓消费同一补点序列；子枝、单点根枝、空芽不加。`startLeadRatio=0` 不补点。不改变生长路径、距离、宽度、调用点索引、分叉位置、叶茎及 Chance 数值。 |
| 连接父侧距离比例 | `connectionParentRatio=0.15`，范围 0–2，步长 0.01；乘子侧根宽 W，控制实际父边界上的局部展开与父切向控制柄，展开上限 2W。精确公式见[连接状态](tree-connection-repair.md)。 |
| 连接子侧距离比例 | `connectionRootRatio=0.15`，范围 0–2，步长 0.01；乘 W，控制子侧有限过渡终点与控制柄；终点最多到子侧位置长度的一半。两个比例为零仍保留基本宽度过渡。 |
| 叶茎系数 Ks、时间尺度 τs | S=Ks ln(1+t/τs)，默认 τs=1000ms。 |
| 叶茎反向偏好 b | p右=0.5−b sin θ；默认 b=0.5。树向右，叶茎更可能向左；竖直时各半。未进行面积碰撞检测。 |
| 叶茎倾角 α | 叶茎方向=侧别×枝干法线×cos α+枝干切线×sin α。 |
| 叶茎上翘倍数 B、控制点比例 cx/cy、末端比例 ey | 局部二次曲线起点 (0,0)，控制点 (S cx,−S cy B)，终点 (S,−S ey B)。上翘指局部坐标的负 y，并非总是屏幕向上。 |
| 叶茎完成位置与宽度 | 优先使用有限的 `call.events[0].finished_at_ms`，否则使用 `startMs+(durationMs??0)`。完成时间经调用开始时间之间的距离映射得到 d_s，保存为 `BranchSection.y`；单位置枝为 0。起点为 d_s 的中心线，方向与宽度取该处局部值。填充宽度 w=min(stemWidth,stemWidthRatio×localWidth)，`stemWidth` 为最大宽度；`stemWidthRatio=0.9`，范围 0–1，步长 0.05。 |
| 叶长上下限、叶片时间尺度 τl、参考时长 T | l=lmin+(lmax−lmin)min(1,ln(1+t/τl)/ln(1+T/τl))。T 时达到最大值；τl 默认 1000ms，独立于叶茎 τs，调整叶茎不改变叶长。 |
| 叶宽比例 r | 尖叶最大宽度=l r，默认 r=0.30。用两段三次曲线从叶柄端点连到叶尖，半宽控制点高度为 2lr/3，实际最大半宽为 lr/2。 |
| 叶在茎上的起点 q | 多片叶的曲线参数 u=q+(1−q)i/(n−1)；单片叶 u=1。不是弧长比例。 |
| 叶片散开角 γ、反侧概率 p | 叶角=叶茎局部切线角±γ；以 p 选择 −侧别。γ 为固定偏转幅度，不是最大随机角。 |
| 叶柄长度 h | 从叶挂点画长度 h 的线，叶片从 h 延伸到 h+l。 |
| 固定叶脉起止比例 | 叶脉从 h+0.1l 到 h+0.85l，不提供调参入口。 |
| 空枝芽长宽 | 椭圆半轴分别为长/2、宽/2，沿子枝初始方向放置。 |
| 模型端点圆 | 无工具调用时画给定半径的圆。 |
| Chance 半径比例 c | 默认 c=0.05。单候选时，几何半径等于 c 乘子枝实际根宽，圆心位于按实际首段方向选侧的父枝外沿。零个或多个候选时，圆心和半径基准取自父枝采样位置和宽度。子枝起点始终位于父枝中心线。非零几何半径画为圆环，屏幕半径至少 3 CSS px，描边 1.5 CSS px。几何半径为零时隐藏圆环。 |
| 固定节点局部原点 | 节点内部 x 参考值为 64，同时补偿节点位置；不应改变最终世界位置。 |
| 固定描边、透明度 | 叶茎使用无描边的同枝色填充轮廓和半径 w/2 的端帽；叶柄线宽 1.4、叶片描边宽度 1、叶脉线宽 1、叶片 opacity 为 1；外层状态透明度仍生效。这些值不提供调参入口，也不接受链接或本地存储覆盖。 |

叶宽比例、叶茎倾角、叶茎上翘倍数支持“固定值 / 范围随机”模式选择。固定模式只显示模式选择和固定值输入框／滑杆；范围随机模式只显示模式选择和上下限输入框／滑杆。显示条件在同一份字段元数据中按参数键声明，不按中文标签匹配；切换只改变控件显示，不清空隐藏值。叶宽、上翘及倾角基础值为 min+(max−min)U；U 由对象 ID 和参数名稳定生成，刷新不会重抽，交换上下限不会报错。倾角最终选择还要比较下文的同侧角度间隔。子枝夹角只有范围参数，上下限相等时得到确定角度。参数仅通过当前浏览器同源的 localStorage（`ascout-tree-tuning`）保存和恢复；未知字段忽略，非对象存储回到默认值，非法数值回到该字段默认值。URL 不读取或写入调参值；页面打开时清理已知调参键（含七个固定绘制值的同名键），保留其它查询参数、`tune` 面板开关与 hash。本地存储不可用时，本次页面内仍可调参，重新打开使用默认值。

K ln(1+d/τ)=ln((1+d/τ)^K) 的等式成立，但不能消去两个自由参数。只有 d 远小于 τ 时，L 近似 (K/τ)d。K 不缩放枝宽和叶片，所以也不是全局缩放。

最小枝宽是可见性下限，不是调用语义要求，可设为 0。参考时长来自有上下界叶长映射的归一化需要，不是物理必需量。当前末端仍为平口。

## 几何边界与本轮验证（2026-11-12）

节点包围盒在两轴保守扩展，包含枝干平滑控制点、叶茎曲线控制范围、叶片轮廓、叶柄与描边、模型端点、旋转空芽及 Chance 几何圆。`offsetX/offsetY` 与节点位置相互补偿，包围盒和局部原点改变不移动世界坐标。保守边界可能留白。Chance 圆环的屏幕可见性下限可超出其几何包围盒，初次取景预留的边距覆盖这部分。

空枝无纵向枝段，保留 Chance 与后代，后代从局部起点挂接。无候选 Chance 使用 Instrumentation 准入请求时间映射后的父枝采样位置与宽度；该时间不表示候选已启动。

子枝被接受后，父枝按对应 Proposal 的 `match` 完成时间截取原时间映射，最多画到原最后调用位置，不另造尾段；截止后的调用仍在原 Branch 详情中。截止前开始的模型调用保留，完成锚点限制在可见范围。截止位置的短横线及其 bounds 使用同一份几何；验证或准入时间缺失时明确报错。

无模型验证：`/tmp/opencode/system-tree-run/quality.cjs` 手工构造空枝、单次调用、空枝下嵌套后代、无候选 Chance，以及范围初角／倾角、最大上翘、宽叶和长叶柄；3 个节点、3 个 Chance、16 个可见 SVG 元素均在节点边界内。局部原点分别取 64 和 500，世界位置最大误差约 1.14e-13；Enter 提交、面板拖宽、随机模式刷新保留及未知存储键均通过，无 JS 错误。此为抽样边界验证，不代表穷举全部参数组合。

叶茎按完成距离排序，逐根比较两侧角度间隔。每侧邻居包括当前叶茎长度 S 距离内的全部子枝与已放置叶茎；子枝角度为夹角，叶茎角度为 ψ=90°−倾角。选择与邻居最小角度间隔最大的侧别和倾角，侧别同分保留稳定偏好，倾角同分优先靠近稳定基础值，再取较小值。固定模式只比较同一个倾角；随机模式在上下限之间取含两端的八个等分点作为候选，基础值仍由 ID 稳定采样。同侧角度避让不是面积碰撞检测，不保证叶片无重叠。

叶茎二次曲线均匀取 17 个参数位置，变换到本枝坐标后按导数单位法线偏移 ±w/2，以 `outlineCurves` 生成两侧。叶片先生成；本枝根部连接完成后，叶茎与本枝最终可见侧边调用同一直接构造，父侧与子侧参数距离分别为连接比例乘 w。零宽或零长度保留普通闭合轮廓。边界直接纳入填充控制点和端帽半径，叶片边界算法不变。

## 绘制与边界共享几何（2026-11-12）

当前直接构造验证材料见 `/tmp/opencode/constructive-connection/report.md`。原有事件、完成锚点、路径、宽度和 placement 与基线逐字段比较；局部连接外形允许变化，视觉验收由用户完成。

用户已批准最小共享几何，不进行大规模文件拆分。`geometry.ts` 中树枝生成路径和实际三次曲线控制点；叶茎生成锚点、局部二次曲线路径及控制点、旋转和模型端点；叶片生成曲线上挂点、旋转、尖叶轮廓、叶柄与叶脉路径及线宽。空芽和 Chance 圆也在此生成一次。`BranchNode.tsx` 只读取这些结果画 SVG；`treeGraph.ts` 只把已生成的 Chance 圆关联到观察事实。

边界计算直接消费同一份路径控制点、椭圆和旋转结果。Bezier 曲线使用控制点包围范围，旋转椭圆使用其局部矩形四角，描边加半线宽；这是保守边界，不是最小紧包围盒。节点位置与 offset 互相补偿，收紧边界不会移动实际世界坐标。

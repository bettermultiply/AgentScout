# 投机树绘制参数

参数、默认值、范围和面板标签集中在 `webui/src/tree/tuning.ts`；归一化范围从同一份面板字段定义派生，不另维护。长度为树坐标单位，缩放 z 时一个单位对应 z 个 CSS 像素。面板按树枝、叶茎、叶片、整体分类；树枝组包含段长、方向、粗细、采样、子枝初角、空芽与 Chance 标记。整体组只放共同坐标参考，当前为节点局部原点，不是形态或整体缩放控制。数值输入与滑杆并列，数值输入按 Enter 或离开输入框生效；面板右侧拖柄或左右方向键调整宽度。打开时通过面板 header 的“收起”按钮关闭，关闭后保留“调参”入口；两者不同时显示，避免窄树窗中互相遮挡。header 随面板滚动保持可见。

## 公式

下面 d 是相邻调用开始时间差，t 是调用耗时，clamp 表示限制在给定范围。

| 参数 | 公式与含义 |
| --- | --- |
| 段长系数 K、时间尺度 τ | L=K ln(1+d/τ)，默认 K=60、τ=10000ms。K 线性缩放枝段长度，τ 改变时间映射的弯曲程度。URL `tau` 直接使用毫秒，不作换算；面板以秒显示，`scale=1000` 只用于面板输入／显示及派生范围，面板范围 0.5–600 秒对应内部 500–600000 毫秒。 |
| 每截转角 δ、回中范围 R、最大倾角 A | p右=clamp(0.5−[(x−原点)+R sin θ]/(2R),0,1)；θ下一截=clamp(θ±δ,−A,A)。方向按 p右 抽取；默认 δ=18°、R=60、A=72°。 |
| 采样步长 g | 每截分成 max(1,ceil(L/g)) 小步，方向按 3u²−2u³ 插值，位置累加 (sin θ,cos θ)L/步数。 |
| 根宽 W、宽度指数 e、最小枝宽 m | w=max(m,W(剩余调用数/总调用数)^e)，默认根宽 9、e=0.1、m=1.2。当前位置的调用已从剩余数中扣除，因此实际根部可能略小于 W。 |
| 子枝夹角范围 | `childAngleMin=30`、`childAngleMax=90`；两个字段各自范围 5–90°、步长 1°。β=min(a,b)+abs(b−a)×stableRandom(`${id}/childAngle`)，交换上下限结果相同。先使用稳定随机偏向选侧；若该侧初始绝对方向超过 90°，选择另一侧，水平允许。范围内夹角用于初始方向；实际首段仍参与逐截方向插值，不保证首段与父枝的实际夹角等于 β。 |
| 父枝宽度过渡 | 条目位置的宽度取该位置及之前条目扣除后的剩余工作量对应值；条目之间用 smoothstep 平滑过渡，条目位置的数值保持不变。 |
| 连接父侧距离比例 | `connectionParentRatio=0.15`，范围 0–2，步长 0.01；W 为子枝原始 `trunkWidths[0]`。从每侧首交点沿父枝实际可见闭合轮廓、远离另一侧交点取单侧距离 0.15W，实际距离上限为父闭合轮廓周长的 1/4。 |
| 连接子侧距离比例 | `connectionRootRatio=0.15`，范围 0–2，步长 0.01；从每侧首交点沿该子枝外沿向末端取单侧距离 0.15W，受剩余外沿长度限制。两个距离独立；缺少任一侧交点或有效距离为零时连接返回 null，显示普通枝干轮廓。 |
| 叶茎系数 Ks、时间尺度 τs | S=Ks ln(1+t/τs)，默认 τs=1000ms。 |
| 叶茎反向偏好 b | p右=0.5−b sin θ；默认 b=0.5。树向右，叶茎更可能向左；竖直时各半。未进行面积碰撞检测。 |
| 叶茎倾角 α | 叶茎方向=侧别×枝干法线×cos α+枝干切线×sin α。 |
| 叶茎上翘倍数 B、控制点比例 cx/cy、末端比例 ey | 局部二次曲线起点 (0,0)，控制点 (S cx,−S cy B)，终点 (S,−S ey B)。上翘指局部坐标的负 y，并非总是屏幕向上。 |
| 叶茎起点比例 a | 起点=枝中心+侧别×法线×枝宽×a；a=0.5 在边缘。 |
| 叶长上下限、叶片时间尺度 τl、参考时长 T | l=lmin+(lmax−lmin)min(1,ln(1+t/τl)/ln(1+T/τl))。T 时达到最大值；τl 默认 1000ms，独立于叶茎 τs，调整叶茎不改变叶长。 |
| 叶宽比例 r | 椭圆宽度=l r。 |
| 叶在茎上的起点 q | 多片叶的曲线参数 u=q+(1−q)i/(n−1)；单片叶 u=1。不是弧长比例。 |
| 叶片散开角 γ、反侧概率 p | 叶角=叶茎局部切线角±γ；以 p 选择 −侧别。γ 为固定偏转幅度，不是最大随机角。 |
| 叶柄长度 h | 从叶挂点画长度 h 的线，椭圆中心位于 h+l/2。 |
| 叶脉起止比例 v0/v1 | 叶脉从 h+l v0 到 h+l v1。 |
| 空枝芽长宽 | 椭圆半轴分别为长/2、宽/2，沿子枝初始方向放置。 |
| 模型端点圆 | 无工具调用时画给定半径的圆。 |
| Chance 半径比例 c | 半径=c×子枝实际根宽；默认 c=0.05。子枝起点位于父枝中心线，Chance 圆心位于按实际首段方向选侧的父枝外沿；两者坐标不相同。无候选时使用父枝采样位置与宽度。 |
| 节点局部原点 | 节点内部 x 参考值，同时补偿节点位置；不应改变最终世界位置。 |
| 描边、透明度 | 叶茎、叶柄、叶片、叶脉使用各自线宽，叶片 opacity 为透明度。 |

叶宽比例、叶茎倾角、叶茎上翘倍数支持“固定值 / 范围随机”模式选择。固定模式只显示模式选择和固定值输入框／滑杆；范围随机模式只显示模式选择和上下限输入框／滑杆。显示条件在同一份字段元数据中按参数键声明，不按中文标签匹配；切换只改变控件显示，不清空隐藏值。随机模式值为 min+(max−min)U；U 由对象 ID 和参数名稳定生成，刷新不会重抽，交换上下限不会报错。子枝夹角只有范围参数，上下限相等时得到确定角度。参数保存在链接及本地存储；未知字段忽略，非对象存储回到默认值，非法数值回到该字段默认值。

K ln(1+d/τ)=ln((1+d/τ)^K) 的等式成立，但不能消去两个自由参数。只有 d 远小于 τ 时，L 近似 (K/τ)d。K 不缩放枝宽和叶片，所以也不是全局缩放。

最小枝宽是可见性下限，不是调用语义要求，可设为 0。参考时长来自有上下界叶长映射的归一化需要，不是物理必需量。当前末端仍为平口、叶片为椭圆；枝端和叶形选择待用户确认，不臆定选项。

## 几何边界与本轮验证（2026-11-12）

节点包围盒在两轴保守扩展，包含枝干平滑控制点、叶茎曲线控制范围、随机叶宽、叶柄与描边、模型端点、旋转空芽及 Chance。`offsetX/offsetY` 与节点位置相互补偿，包围盒和局部原点改变不移动世界坐标。保守边界可能留白，不是最小紧包围盒。所有可见描边随树内坐标缩放。

空枝无纵向枝段，保留 Chance 与后代，后代从局部起点挂接。无候选 Chance 使用采样得到的二维位置。

无模型验证：`/tmp/opencode/system-tree-run/quality.cjs` 手工构造空枝、单次调用、空枝下嵌套后代、无候选 Chance，以及范围初角／倾角、最大上翘、宽叶和长叶柄；3 个节点、3 个 Chance、16 个可见 SVG 元素均在节点边界内。局部原点分别取 64 和 500，世界位置最大误差约 1.14e-13；Enter 提交、面板拖宽、随机模式刷新保留及未知存储键均通过，无 JS 错误。此为抽样边界验证，不代表穷举全部参数组合。

面积避让尚未实现。概率反侧偏好不等于面积避让，当前默认参数不构成叶片无重叠的保证。

## 绘制与边界共享几何（2026-11-12）

用户已批准最小共享几何，不进行大规模文件拆分。`geometry.ts` 中树枝生成路径和实际三次曲线控制点；叶茎生成锚点、局部二次曲线路径及控制点、旋转和模型端点；叶片生成曲线上挂点、旋转、椭圆、叶柄与叶脉路径及线宽。空芽和 Chance 圆也在此生成一次。`BranchNode.tsx` 只读取这些结果画 SVG；`treeGraph.ts` 只把已生成的 Chance 圆关联到观察事实。

边界计算直接消费同一份路径控制点、椭圆和旋转结果。Bezier 曲线使用控制点包围范围，旋转椭圆使用其局部矩形四角，描边加半线宽；这是保守边界，不是最小紧包围盒。节点位置与 offset 互相补偿，收紧边界不会移动实际世界坐标。

共享几何的无模型抽样验证材料为 `/tmp/opencode/system-tree-run/quality.cjs` 与 `panel-shared.cjs`，覆盖边界、DOM 属性、局部原点、面板收起展开、数值输入与存储。这些材料不代表当前默认参数的完整视觉验收，也未穷举全部参数组合。

工作区树形改造基于尚未提交的 `tree/`、`treeGraph.ts`、调用配对和混合 UI／观察类型改动，`dist` 也包含当前其他源改动。本轮不通过整体暂存把这些既有修改和无关 NLE／回放工作混入提交；留待主 Agent 审查与拆分。

## 固定分叉平滑连接（2026-11-13）

保留 React Flow + SVG。纯几何模块为 `webui/src/geometry/curves.ts` 与 `webui/src/geometry/smoothConnection.ts`，不依赖 React、SVG 字符串、BranchState 或参数 store。`webui/src/tree/geometry.ts` 提供父枝实际可见闭合轮廓和子枝两侧外沿，调用方转换 SVG，bounds 消费同一闭合序列的端点与控制点。

连接按“每侧首交点 → 两个单侧距离 → 三次相切曲线 → 闭合轮廓”生成；单位置父枝使用 `roundedBase` 圆根，空枝不生成连接。具体公式、null 退化和验收边界见 [根部连接状态](tree-connection-repair.md)。

第二阶段严格验收未通过：V3 有 28 个外部根点，V7 漏盖 8 点且多出 262 点，231 次分叉仅 18 次成功连接；成功连接数量不等于任意交点数量。V11 数量齐全但 null 图缺少标记。第三阶段只同步默认值与文档，不修复上述算法或图示缺口，不宣称整体或视觉验收通过。

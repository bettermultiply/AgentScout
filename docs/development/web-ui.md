# 控制面 WebUI（2026-11-10）

2026-11-13 根部连接采用实际可见父边界位置映射与有限子侧过渡，直接构造两条三次曲线和闭合填充，保留 React Flow + SVG；连接与 bounds 共用控制点。子枝起点在父中心线、Chance 在父外沿，叶茎 placement 不变。用户已检查并接受当前画面，尚未穷举极端参数；公式与限制见 [连接状态](tree-connection-repair.md)、[投机树绘制参数](tree-parameters.md#固定分叉平滑连接2026-11-13)。

控制面 WebUI 是 `--web` 模式下的正式浏览器界面。它只读取控制面已经发布的观察事实与按 Branch 的对话接口，不接触 Speculative Tree、控制命令或 Runtime 内部对象；输入仍走 `POST /api/request`。

## 技术组成

- React 19 + TypeScript，React Flow 绘制投机树，Zustand 保存观察状态。
- Vite 构建；源码位于仓库根目录 `webui/`。前端构建需要 Node 22.12 或更新的版本（当前验证使用 Node 26）。
- 构建产物位于 `webui/dist/`，不提交到仓库，由 `src/bin/ascout-control-plane.rs` 用 `include_bytes!` 嵌入 Rust 二进制，交给 Gateway HTTP 入口提供。`cargo build` 不会自动启动前端工具链，必须先手动构建前端。
- `webui/dist/index.html`、`webui/dist/assets/app.js`、`webui/dist/assets/app.css` 与 `webui/dist/favicon.svg` 是嵌入入口；控制面按固定路径提供它们。

### 生产构建

首次克隆仓库及前端源码变化后，先在 `webui/` 运行 `npm ci && npm run build`，再回到仓库根目录运行 `cargo build`：

```sh
cd webui
npm ci && npm run build
cd ..
cargo build
```

`webui/dist/` 已列入根目录 `.gitignore`。缺少嵌入文件时，`cargo build` 会在 `include_bytes!` 嵌入阶段编译失败；前端源码变化后未重新构建，则二进制仍提供旧界面。

## 界面行为

左侧默认显示独立的“权威窗口”用户视图，跟随当前权威 Branch，展示从任务开始到当前的 `inherited`、消息与流式内容连续阅读流；它不显示 Branch 生命周期状态并允许输入。也可以切换到具体 Branch 窗口：继承自父 Branch 的消息与当前 Branch 的消息按先后顺序连续渲染，不折叠、不插入分隔线，当前权威 Branch 显示“当前权威窗口 · id”，历史权威 Branch 显示“id · 状态”，并在窗口标识中显示角色与状态徽标；历史 Branch 只读。发送后消息立即以“发送中”状态显示，服务器回显同一用户消息后移除临时条目，失败时显示错误。第一个版本从观察事件推导任务列表，控制面没有单独的任务列表接口。

右侧是可隐藏的投机面板，默认显示投机树；点击顶部种子、工具叶片或模型叶茎进入该 Branch 的只读详情，可以返回树。树上不显示分支名，子枝不重复绘制枝头；悬停显示 Branch id、模型、token、Chance 字段、结算与调用/事件摘要。候选未采纳使用中性状态文字，不把用户视图描述为已清理。

### 投机树与统计

面板顶部汇总当前投机数量、累计 token、累计费用、累计节约时间和累计节约金钱。`settlement.time_ms` 与 `settlement.money` 的实测部分和估计部分分开累加、分开显示，不合并成一个数字；没有结算数据时显示“暂无数据”，不用其他数字填充。

树以 Branch 树自身为几何依据，枝长和粗细都是观察事实的函数。布局前先配对：每次工具调用归到它之前最近的那次模型调用，形成“模型调用 + 它发出的工具调用”的单元；找不到所属模型的工具调用属于数据缺陷。所有调用必须带 `started_at_ms`：缺失时整棵树显示错误，不跳过、不用事件序号补时间。纵向位置逐截计算：第一次调用位于 0，之后每两次相邻调用开始时间之间是一截，默认长度为 `60 × ln(1 + 间隔/10000ms)`，位置逐截累加；间隔相同的两截长度相同。Chance 不切分截长，只在相邻两截之间按创建时间线性插值。枝长终止于最后一次调用，丢弃或清理等生命周期事件不延长枝长；没有尾段、最小长度或空枝固定长度。多个调用时间相同时，它们共用同一纵向位置，不产生零长采样段；只有一个位置时仍按该处枝宽绘制横截面。

枝的粗细按该位置扣除工作量后的剩余调用占比计算，条目间用 smoothstep 过渡；默认宽度指数为 0.1、最小枝宽 1.2。根宽是独立树内参数（默认 9 单位），不随时间映射变化。子枝根宽为父枝分叉处宽度乘以该子枝调用数在相关剩余调用中的占比的 0.1 次方；指数可调，详见参数文档。普通枝末端平口结束，单位置父枝的非空子枝使用圆根。

子枝从 Chance 创建记录时刻对应的父枝中心线位置分出。偏向侧别由分叉点相对本枝起点轴的横向偏移和稳定哈希决定，向右概率为 `clamp(0.5 - (local.x - nodeOrigin)/(2R), 0, 1)`；初始相对夹角在默认 30–90° 范围内用 `${id}/childAngle` 稳定采样，偏向侧初始绝对方向超 90° 时选另一侧。实际首段参与逐截方向插值；其在父枝局部法线上的投影决定父外沿上的 Chance 侧别，不移动子枝中心线起点。

枝的弯曲是逐截随机行走：每截有一个相对于上一截的方向角。横向位置以本枝起点轴为零点，向右为正；默认向右概率 `p = clamp(0.5 − (x + 60 × sin θ) / 120, 0, 1)`，用该截末次调用标识的稳定哈希决定左右，每截转 18°，下一截方向角限制在 ±72°；初始方向按子枝选侧规则确定。每一截只依赖它之前已经画出的位置与方向，因此追加更晚的调用不会改变已画出的前缀。

一个 Branch 是一根大枝。每次模型调用是一根短叶茎：完成时间映射到枝的中心线位置，以当地切线和宽度生成同枝色无描边的填充轮廓。长度为 `10 × ln(1 + 模型秒数)` 树内单位，没有屏幕像素上下限；宽度取最大宽度与局部枝宽比例上限的较小值。叶茎与本枝最终可见轮廓进行两侧平滑连接；无有效连接时保留普通闭合轮廓，端部画半径为半宽的端帽。单位置枝仍显示其实际截面。叶茎按完成距离依次对附近同侧子枝和已放叶茎比较角度间隔，侧别同分保留稳定反侧偏好；固定倾角保持固定值。模型调用发出的工具调用是叶茎上的叶片，沿茎排开，叶长随工具耗时在 10–24 树内单位之间变化；叶片画成椭圆，没有尖端；中脉为本色偏暗的细线。叶片只按角度散开，不做面积避让。参数与精确规则见 [树形参数](tree-parameters.md)。

状态只改样式，不移动任何枝干。当前权威是近白（浅色主题近黑）实色；曾经是权威的枝，包括已经结束、已经让位给当前权威的旧主干，保持同色，但按 72% 与背景混合成较淡的实色，不使用透明度，避免透出下层子枝的颜色；从种子到当前权威仍然是一条白线，只在旧权威段略微变淡。运行中的候选为粉紫；未采纳或未晋级就被清理的枝为灰色、整枝 40% 透明、叶片统一变枯。调用状态是另一个通道：成功为实心绿，失败为实心红，取消为空心灰，超时为空心琥珀；候选枝上的成功叶改用该枝的玫红（`--leaf-candidate`），避免粉枝绿叶的割裂，失败/取消/超时仍用各自的颜色。枝的透明度包住叶片，所以未采纳枝上的叶子不会保持鲜绿。均不用虚线。叶茎只有一种颜色来源：所属 Branch 的显示状态。不会再出现“叶子在树上分叉点以下就变粉、但所在 Branch 仍是白干”的两套规则。

每个 Branch 是一个 React Flow 节点；非空枝有连接时使用连接闭合轮廓，null 时使用普通枝干。Chance、叶茎、叶片与芽在同一随 React Flow 变换的 SVG 组中。存在子枝时 Chance 圆心在父外沿，子枝起点在父中心线，默认半径为子枝实际根宽的 0.05 倍；无候选时使用父枝采样位置与宽度。真实缩放同时缩放圆点和全部墨迹。空 Branch 的芽为沿初始方向放置的实心椭圆，不生成连接。

曲线按固定空间间隔采样，成本随可见长度线性增长，不通过反解对数遍历逻辑时钟。方向由逐截行走决定，追加事件不会改变已有前缀。初始 fit 按实际枝干、叶片、叶茎、Chance 和芽的墨迹包围盒计算，目标上下各 50px 并水平居中；缩放上限 4 倍。暗色权威色为 #F4F8FC，浅色近黑，候选为粉紫，未采纳为灰并整体淡化，枯叶为 #9C8A6E（浅色 #8A7A5C），与图例一致。

调用密集时相邻叶簇可能重叠，当前不做面积避让。连接覆盖、额外材料与 null 图标记存在严格验收缺口，见连接状态文档；几何辅助量与截图证据分开报告，不以脚本运行完成声称整轮通过。

### 临时调参（2026-11-12）

树面板右上角的“调参”按钮打开临时参数面板；带 `?tune=1` 打开页面时默认展开。面板实时调整段长系数 `segmentK`、时间尺度 `segmentTauMs`、每截转角 `turnStepDeg`、回中范围 `recenterRange`、最大倾角 `maxLeanDeg`、根宽 `rootWidth`、宽度指数 `widthExponent`、最小枝宽 `minTrunkWidth`、叶茎系数 `stemK`、叶长上下限 `leafMin/leafMax` 与叶茎宽度 `stemWidth`。参数同步写入地址栏（短键 `k`、`tau`、`turn`、`recenter`、`lean`、`rootw`、`wexp`、`wmin`、`stem`、`lmin`、`lmax`、`swidth`），并保存到浏览器本地存储；刷新、复制链接或下次打开同一浏览器都能复现；“重置”恢复默认值。该面板只改绘制参数，不改观察事件、控制状态或布局语义，仅用于形态调整，不是正式用户功能。

分支详情包含基本信息（角色、状态、模型、Chance、投机起点、存活时长）、隔离环境（独立 Instance、嵌套关系、配置摘要）、用量（逐次模型调用、工具调用）和该 Branch 的只读对话。详情的对话与主对话一样连续显示继承内容，不为详情单独折叠。工具调用表包含工具名与状态；模型调用表的动作列为未配对时显示“未配对”。环境字段为 null 时显示“未上报”，不推测值。

状态折叠是纯函数：`foldEvents(events, upToSequence)` 可以得到任意序号的前缀状态。当前版本没有实现回放界面。

## 当前缺口

公共观察事件尚未提供 Proposal 的真实验证时刻；父枝保持按自己的全部调用绘制，尚未实现采纳后的验证点截止及端点标记。

绘制参数及公式见 [投机树绘制参数](tree-parameters.md)。参数集中于 `tree/tuning.ts`，支持数值输入、滑杆、固定/范围随机；临时调参面板自身的宽度调整见该文档，整个投机面板调宽见上文。

树上 Chance 的圆半径等于对应子枝根宽的一半；缺少对应 Branch 的 Chance 也显示圆点，不冒充 Branch。空 Branch 由自己的节点画出实心椭圆芽。

- 枝段长度按相邻调用开始时间差逐截计算；缺少 `started_at_ms` 时整棵树报错。Chance 按创建记录时间在相邻两截之间插值并限制在枝端范围内。该记录时间由 Ledger 追加时生成，尚不等于投机开始时间；候选 Branch 已有源侧投机开始字段，无候选 Chance 尚缺此字段。
- 树的横向位置由逐截随机行走与回中概率决定；还没有按整棵树的墨迹质量做配平，长枝多的一侧可能更宽。
- 没有任务列表接口；任务从事件中的 `task_id` 推导，首个事件到达后才会出现。任务切换状态保留在客户端。
- 通用观察事件仍没有事件级回放界面；纯折叠函数可以截取到任意序号。NLE 的独立地图页面另有动作历史浏览，且当前只使用演示公开观测。
- NLE 地图浏览位于独立的 `/map` 入口；它读取同一 task 的真实 Runtime `nle_map_action` 公开观察事件，作为跨 Promote 的权威窗口历史；Branch 只显示为动作来源，不按单 Branch 筛选。没有事件时才使用明确标注的演示序列；不同 task、乱序或无效事件仍不会被伪造为同一条完整时间线，详见 `docs/development/nle-map.md`。
- 对话正文仍按需读取；权威窗口按 `authorityHistory` 依次读取并连续展示已成为权威路径的内容，按 Branch 查看仍是独立窗口。消息组件使用稳定身份和 memo，观察事件只使末尾数据刷新，滚动仅在用户仍贴近底部时跟随；Ledger 的 transcript 保存权威 session 文件的消息引用，正文存于该文件，继承由记录父链表达；这些内部引用没有进入公共观察事件，不能把文件中的全部候选旁支当作已生效对话。
- 模型投机当前没有生产路径；面板按事件结构显示，不假设模型投机一定发生。
- `tool_finished.tool_name` 只在接入侧报告过同一 action 的 `ActionStarted` 时存在；只有准入请求时该字段为 null，界面显示“未上报”。
- 统计只累加已上报事实。`model_usage` 缺 token 或费用时不补零；结算的实测/估计部分缺失时对应项显示“暂无”。

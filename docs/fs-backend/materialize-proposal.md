# Authority 物化

## 已确定的责任边界

当前 accept 把结果写入目标环境的 upper；权威环境的写入也停留在各挂载的
upper 中，宿主真实 workspace 不会自动收到这些写入。

系统最终必须把 Authority 的结果物化到现实；候选接受不意味着立即物化。
候选被接受并承接后续执行时，保留并继续使用候选环境，不默认把候选改动复制回
父分支。必要状态交接及环境引用仍须正确处理；嵌套接受不能越过祖先未决依赖，
不能因此提前物化。不新增环境迁移模式或 Policy 选择接口。

正常完成时，仅在任务完成、没有存活候选且任务相关写入完成后物化，并重置
Authority 的基准；不为了物化暂停执行。取消、失败或终止任务时立即进入物化
处理，先结束候选并等待任务相关写入完成，再实际写回。
Agent 常用的 Ctrl-C 或退出均终止任务；Ctrl-C 保留程序和 session，留在对话中，
待候选结束、相关写入及物化处理完成后可接下一轮。物化失败须显示失败，不能宣告成功。
暂停任务由 AScout 提供独立于原 Agent 的 `/pause` 入口，明确继续命令为 `/continue`，
恢复原任务执行，保留原树、候选和环境关系；普通消息是否也解除暂停未定。
它与原 Agent 的 Ctrl-C／退出终止语义分开，不意味着退出程序。
任务（task）是 session 中 Agent 的一轮工作；Agent 完成本轮工作、开始等待用户
输入时，task 完成。一个 session 对应一个 AScoutAgent 和一棵投机树，task 完成
不意味着 session 或树结束。一次操作结束本身不等于本轮工作完成。

Runtime 负责内部整理，并通过接入边界向控制面报告物化完成或失败。物化失败
等同操作失败；控制面负责对外宣告任务成功，必须等待物化成功，不能仅凭 Agent
开始等待输入便报告成功。当前通过 Runtime 的 `MaterializeAuthority` 返回结果，
控制面收到成功后记录 task 完成；失败保留发布资料并等待重试。

## 写入与引用前提

物化只需确认任务相关写入完成，不要求整个宿主的写者全部静止。没有存活候选
或现有 `Suspended` 状态本身不能替代写入完成事实。运行期间不编辑宿主目录是
使用约定，不将其扩展为宿主锁或禁止所有外部写者的机制要求。
物化与重置基准不能破坏仍被引用的环境和 fork/diff 基准；旧环境及旧基准在无人
引用时释放，不能仅因任务结束就删除。

## 宿主写入要求

写回范围包括工作目录及任务允许修改的其他挂载，只落实 Authority 相对基准的
改动，包括文件内容、删除及首版支持的权限位变更。文件属性变更的首版范围仅为
权限位；其他属性不新增修改支持，其扩展范围留待后续，不阻塞首版。
这一范围限制不允许物化破坏原文件未改属性或链接结构；写回与原子替换实现仍须
满足该保留要求，不能因未提供其他属性的修改支持便将它们丢失或重置。无法满足
保留要求的情形须明确报告能力限制，不能静默破坏。其他属性的具体处理方案未在
本轮确定。
从增量层选择受影响路径，由内核解释 Authority 的最终视图后写回。同路径由
Authority 覆盖，未涉及路径保持不变。不比较宿主与共同祖先，不做 Git diff/merge，
不新增全量哈希，也不复制整个挂载。不能只把 upper 的原始目录直接复制回宿主；
删除、opaque、redirect 和 metacopy 需要按 overlay 语义解释。宿主写入必须约束
中间符号链接，不能沿链接写出挂载边界。

rename、目录删除等会影响多个路径，必须落实完整受影响路径集合，包括源、目标及
其后代。仅受影响子树需要读取完整最终内容，不扩展为整个挂载扫描或复制。

## 覆盖与部分失败

2026-11-14 用户确认：直接写入，不检测或报告物化冲突。运行期间不将用户正常
编辑宿主目录作为预期使用方式，不为被覆盖的宿主版本保留可恢复副本。

暂允许读者看到写回中间态。部分写回失败时保留已写部分，重试剩余部分，不承诺
回滚。物化失败阻止任务成功报告。写入完成后正常退出，结果应对宿主可见；不新增
掉电保证。

## 实现与验收边界

- 当前已接入任务完成、写者结束等待、失败重试及新 upper 基准替换。
  Pi 会话宿主不持有 Authority overlay；各 Branch 的内建文件工具读取对应运行计划。
- `/pause` 保存树和执行状态，`/continue` 已接入专用控制命令；普通输入继续兼容现状，普通消息是否也解除暂停的目标语义未定。终止与暂停分开。
  恢复使用恢复时宿主普通 bottom lower，不承诺宿主历史内容；受管增量独立保存。
- Ctrl-C/SIGINT 已走保留 session 的 Interrupt；SIGTERM 仍走 Shutdown。
  独立暂停入口的更多 UI 形式未定，实际覆盖见[恢复](../development/recovery.md)。
- 各项实际验证和剩余缺口见 [当前实现状态](current-state.md) 与 [恢复](../development/recovery.md)。
  组合 Runtime 候选环境、扩展工具写者、候选嵌套及存储机制须按实际记录验收，
  局部通过不代表整体完成。
- 属性变更首版仅支持权限位；其他属性修改属于后续扩展，不再列为首版待定。
  权限位物化已有回归；现有普通文件保留宿主 owner、xattr 和时间信息，硬链接目标及
  替换已有 symlink 等不能保证属性保留的情形明确失败。未覆盖全部 ACL、特殊文件和
  链接组合，不将范围收敛等同于全部属性能力已完成。

## 边界

当前 accept 实现只修改指定目标 Backend 环境，不能隐式写宿主 Base；该实现事实
不能代替已确定的候选环境承接规则。
未来内部整理也必须保留 Branch 生命周期、single-winner 与 commit/discard
的既有语义。
